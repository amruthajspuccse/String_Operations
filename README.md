# String Operations

An interactive collection of Python string-operation visualizers built with HTML, CSS, and JavaScript.

## Features

- Forward and backward string indexing
- Interactive string slicing with positive and negative steps
- String concatenation
- String repetition
- Membership operators (`in` and `not in`)
- Step-by-step slicing animations
- Interactive quiz questions in the enhanced visualizer

## Files

- `index.html` — Landing page with links to both visualizers
- `string.html` — Python String Indexing and Operations Visualizer
- `string1.html` — Python String Operations Interactive Lab

## Usage

Open `index.html` in a web browser, then select either visualizer. No server, installation, or Python runtime is required.

The pages run locally and process all input in the browser.
