Forward & Backward Indexing and Word Operations

Forward & Backward Indexing

Left-to-right (positive) vs. right-to-left (negative) indexing.

Forward: 0 to len-1 Backward: -1 to -len
Presets:
>>> s[0]
'P'

Key Teaching Points

  • Forward Indexing: Begins at 0 from the left up to len(s) - 1.
  • Backward Indexing: Begins at -1 for the last character down to -len(s).
  • Formula: negative_index = forward_index - len(s).
  • IndexError: Trying to index beyond limits produces an IndexError.

String Concatenation (+)

Joins two strings to produce a new string.

Binary Operator
>>> s1 + s2
'DataScience'
Concatenated Result
"DataScience"

Key Teaching Points

  • Type Restriction: Python does not permit concatenating a string with an integer directly (e.g. "Age: " + 25 raises a TypeError). Explicit conversion using str() is required.
  • Immutability: Original variables s1 and s2 remain unmodified in memory.

String Repetition (*)

Repeats a string sequence n times.

String * Int
Quick Slider: 4
>>> 'Code ' * 4
'Code Code Code Code '
Result
"Code Code Code Code "

Key Teaching Points

  • Order Flexibility: s * n is equivalent to n * s.
  • Non-Positive Multipliers: Multiplying by 0 or a negative number safely returns an empty string ("").

Membership Operators (in & not in)

Validates whether a target substring exists inside a string.

Returns Boolean
>>> 'Learn' in text
True
>>> 'Learn' not in text
False

Key Teaching Points

  • Strict Case Sensitivity: 'learn' in 'Machine Learning' is False due to capitalization.
  • Empty String Edge Case: "" in s always evaluates to True for any string.

String Slicing (s[start:stop:step])

Extracts sub-segments using index intervals.

[start : stop : step]
Presets:
>>> s[2:8:1]
'MPUTAT'
Extracted Character Sequence:
Extracted Substring
"MPUTAT"

Key Teaching Points

  • Stop is Exclusive: Characters are collected up to stop - 1. The character at index stop is never included.
  • No IndexError: Out-of-bounds slice indices are clipped gracefully without raising errors (e.g. "Python"[2:99] yields "thon").
  • String Reversal: s[::-1] reverses any string via a negative step.
